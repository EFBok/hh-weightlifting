# HH Weightlifting

Static website for HH Weightlifting in Strand — Helderberg Olympic weightlifting since 1950. Built with [Astro](https://astro.build) and `output: 'static'`.

Slice A is a single home page. About, History, Training, and Contact are sections on that page.

## Local development

Install dependencies, then start the dev server:

```bash
npm install
npm run dev
```

The dev server prints a local URL (usually http://localhost:4321).

## Production build

Build the static site, then preview the `dist/` output:

```bash
npm run build
npm run preview
```

`npm run build` writes the site to `dist/`. `npm run preview` serves that folder locally.
